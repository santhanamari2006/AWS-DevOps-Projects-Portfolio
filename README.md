# AWS & DevOps Projects

This repository contains my hands-on AWS and DevOps projects, demonstrating practical knowledge of cloud infrastructure, CI/CD automation, containerization and Kubernetes.

## Projects

**Tools:** AWS, Jenkins, Docker, Kubernetes, Terraform, SonarQube, Trivy, Argo CD, Prometheus, Grafana.

- Automated CI/CD using Jenkins.
- Security scanning using SonarQube and Trivy.
- Application deployment on Amazon EKS.
- GitOps using Argo CD.
- Monitoring using Prometheus and Grafana.

**Tools:** AWS, Terraform, Jenkins, EC2, EKS, Kubernetes, S3.

- Created an Amazon EKS cluster.

**Tools:** AWS, GitHub Actions, Terraform, Docker, Kubernetes, SonarQube, Trivy, Docker Hub.
